# openSMILE Documentation

This directory contains documentation for openSMILE and related tools.

## Documentation Files

### openSMILE Core Documentation
- **openSMILE_book.pdf** - Complete openSMILE reference book
- **components.txt** - Component documentation
- **configfile.txt** - Configuration file format documentation
- **logger.txt** - Logging system documentation
- **knownBugs.txt** - Known issues and bugs

### Developer Documentation
- **developer/** - Directory containing developer-specific documentation
  - messages.txt
  - defines.txt
  - component_configuration.txt
  - implementing_components.txt
  - dataMemory.txt
  - classes.txt

### GitHub Copilot Documentation
- **github_copilot_concepts.md** - Explanation of GitHub Copilot Agent Sessions vs Conversations (English)
- **github_copilot_concepts_ja.md** - GitHub Copilotのエージェントセッションと会話の違いの説明（日本語）

## Quick Start

For installation instructions, see the INSTALL file in the root directory.

For a comprehensive guide to using openSMILE, refer to openSMILE_book.pdf.

For understanding how to use GitHub Copilot with this project:
- English speakers: Read [github_copilot_concepts.md](github_copilot_concepts.md)
- 日本語: [github_copilot_concepts_ja.md](github_copilot_concepts_ja.md)をお読みください
